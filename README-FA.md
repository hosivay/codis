## معرفی

کدیس یک پروژه **اوپن‌سورس** است که به شما امکان می‌دهد متن‌های حساس (یادداشت، رمزها، لینک‌ها و …) را با یک **کلید رمز** رمزنگاری کنید و فقط با همان کلید دوباره باز کنید. خروجی رمز به صورت **کاراکترهای فارسی** نمایش داده می‌شود تا در هر محیطی (چت، ایمیل، یادداشت) به‌راحتی کپی و انتقال داده شود، بدون وابستگی به سرویس خاصی؛ همه‌چیز روی دستگاه شما انجام می‌شود.

این اپ روی **وب، اندروید، آی‌اواس، ویندوز و مک** در دسترس است و برای استفاده‌ی شخصی، تیم‌ها یا توسعه‌دهندگانی که می‌خواهند منطق رمزنگاری را بررسی یا توسعه دهند مناسب است.

---

## امکانات

- **رمزنگاری و رمزگشایی متن** با کلید رمز (پسورد)
- **پشتیبانی کامل از فارسی**: متن ورودی و خروجی رمز با ۶۴ کاراکتر فارسی (شبیه Base64 فارسی)
- **نمایش نتیجه با مارک‌داون**: عنوان، لیست، لینک و … در خروجی رندر می‌شود؛ لینک‌ها با یک کلیک باز می‌شوند
- **متن طولانی**: رمز کردن و باز کردن متن‌های بلند بدون محدودیت عملی
- **کپی، اشتراک‌گذاری و مشاهدهٔ تمام‌صفحه** برای نتیجه
- **تم روشن / تاریک** و **ریسپانسیو** برای موبایل و دسکتاپ
- **ورژن اپ** در پایین صفحه و لینک مخزن گیت‌هاب در هدر

## جزئیات فنی (امنیت و رمزنگاری)

کدیس از الگوریتم‌های استاندارد و امن برای رمزنگاری استفاده می‌کند:

| مؤلفه | توضیح |
|------|--------|
| **کلیدگذاری** | **AES-256-CBC** (بلوک ۱۲۸ بیتی، کلید ۲۵۶ بیتی) |
| **اشتقاق کلید** | **PBKDF2** با **HMAC-SHA256**، نمک ۱۶ بایت تصادفی، ۶۰۰۰ تکرار؛ خروجی ۶۴ بایت (۳۲ بایت برای AES، ۳۲ بایت برای HMAC) |
| **احراز اصالت** | **Encrypt-then-MAC**: بعد از رمز کردن، با **HMAC-SHA256** روی نمک + IV + ciphertext یک تگ ۳۲ بایتی ساخته می‌شود و در رمزگشایی بررسی می‌شود (مقایسهٔ ثابت‌زمان برای جلوگیری از حملات جانبی) |
| **قالب خروجی خام** | `salt (16) \|\| iv (16) \|\| ciphertext \|\| tag (32)`؛ سپس کل این دنباله با **encoding ۶۴ کاراکتر فارسی** به رشته تبدیل می‌شود |
| **Encoding خروجی** | ۶۴ کاراکتر یکتا از اعداد و حروف فارسی (مشابه Base64 ولی با الفبای فارسی)، با نرمال‌سازی ورودی در رمزگشایی (حذف فاصله/خط جدید و نگاشت یونیکد عربی به فارسی) |

## نصب و اجرا

### ۱. کلون کردن مخزن

```bash
git clone https://github.com/hosivay/codis.git
cd codis
```

### ۲. وابستگی‌ها

```bash
flutter pub get
```

### ۳. اجرا

```bash
# وب
flutter run -d chrome

# اندروید
flutter run -d android

# iOS
flutter run -d ios

# ویندوز
flutter run -d windows

# macOS
flutter run -d macos
```

### ۴. ساخت خروجی (Build)

```bash
# وب
flutter build web

# اندروید (APK)
flutter build apk

# اندروید (App Bundle برای فروشگاه)
flutter build appbundle

# iOS
flutter build ios

# ویندوز
flutter build windows

# macOS
flutter build macos
```

خروجی‌ها در مسیرهای استاندارد Flutter (مثلاً `build/web`, `build/app/outputs/` و …) قرار می‌گیرند.

## ساختار پروژه (خلاصه)

```
lib/
├── core/                 # ثابت‌ها، تم، رنگ‌ها، encoding فارسی
├── features/
│   └── cipher/           # قابلیت رمزنگاری/رمزگشایی
│       ├── data/         # Repository و isolate
│       ├── domain/       # CipherService و منطق رمز
│       └── presentation/ # صفحات، ViewModel، ویجت‌ها
├── app.dart
└── main.dart
```

معماری لایه‌ها به صورت **MVVM** و ماژولار است؛ لایهٔ دامنه وابستگی به Flutter ندارد.

کدیس یک پروژه **اوپن‌سورس** است. برای مشارکت:

با گزارش باگ، پیشنهاد قابلیت جدید یا بهبود مستندات هم می‌توانید کمک کنید.
